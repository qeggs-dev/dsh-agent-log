## 演化沙盒 evo-world 新建（2026-11-26）

用户要做「真正使用迭代算法的本地浏览器小游戏」，题材为自然生存——主角生物自己适应玩家创造的环境规则、同时扩大种群；分发目标是 GitHub Pages。落在 `D:\Projects\Deepseek_Harness_Workspace\evo-world\`（独立 git 仓库，初始提交 50083d3）。形态：纯静态 ESM，无框架、无构建、零运行时依赖（`npm run serve` 起 4173）；测试用 `node --test --test-isolation=none "tests/*.test.js"`——**普通 `node --test` 会因 spawn EPERM 失败**（沙箱不允许管道 stdio 的子进程）。机制：每 tick 对全种群跑「6 点采样觅食→进食→代谢扣能量→饿死/老死→能量过阈值繁殖（邻居在 4 格内即均匀交叉，否则自体克隆，再按 mutationRate 高斯点突变，子代代数 +1）」；7 个基因 speed/size/efficiency/tempOpt/tempTol/toxRes/sense，代谢成本=基础+移动(v²)+体型+感知+抗毒+耐温幅度+0.05×超出舒适区度数的平方+1.2×toxin×(1-抗毒)，食物能量 10/单位。调参结论：80×56 网格、`FOOD_REGEN=0.003` 时默认承载约 350~400 只，食物被啃到均值 0.03~0.05 属放牧式平衡而非 bug（承载力由再生通量决定，不由食物存量决定）；`FOOD_REGEN` 取 0.01 会让种群一路顶到上限。视觉：生物颜色 = 最适温度（蓝 98,162,255 → 金 255,208,100 → 橙红 255,86,58，刻意避开绿色），世界底色压成近黑的温度染色，否则 20°C 时绿生物与绿食物糊成一片。验证：33 项测试全绿，含升温 20→38°C 后平均最适温度必须 +8°C 且贴近新气候、降温必须跟随、毒素升到 0.7 后平均抗毒 >0.5、食物 2.2× 种群显著更大、同种子逐位复现；真实 Edge 里升温 34°C 跑 2600 tick 得 opt 33~36、毒素 0.8 得抗毒 0.48~0.88、降到 2°C 得 opt 0.9~7.4。工具：`scripts/probe.js` 打印剧变下的性状轨迹用于调参；`scripts/shot.js` 用 headless Edge + CDP 截图并驱动滑杆/按钮验证接线（本机 `np_exec`/`np_screenshot` 的 playwright 渲染器报 `Cannot read properties of undefined (reading 'includes')`，沙箱内直接启 Edge 又因 Mojo 通道/权限 0x5 失败，必须在 danger-full-access 下跑）。未完成：尚未部署到 GitHub Pages（缺仓库与推送通道）。

## evo-world v3：两界 + 信息素 + 饮食基因（2026-11-26，取代三界版）

用户改口的两条规则：①消费者与分解者不是两个类型，而是同一类「异养生物」，由 diet 基因调控端坐（>=0.5 捕食、<0.5 食腐）；生产者是另一界，吃环境里的无机颗粒。②信息素系统：食物素与警报素两个场，沉积在本格、每 tick 衰减 0.995、每 3 tick 扩散一次；个体按 trail 基因跟随食物素、按 alarmSense 基因决定遇警报是逃还是扑上去（后半即「可被牺牲的个体」）。能量规则：1 碎屑 = 10 能量，生产者×1.2（太阳增益，全系统唯一净输入），异养吃活体得 60%、吃尸体得 60% 且余下 40% 变回碎屑，尸体 700 tick 未处理则腐掉 50% 回碎屑；异养吃盈余生产者有 35% 概率获得光合作用（内共生）。基因 14 个：speed/size/efficiency/tempOpt/tempTol/toxRes/sense/memory/social/fear/kind/diet/trail/alarmSense。实现要点：同种不相残（否则亲代吃自己后代，个体数永远上不去）；空间检索改 regionMembers（区域→成员表），否则随机抽样找不到猎物；生产者按区域密度加拥挤成本 1.1×density，否则会超载 3 倍再崩。调参：初始碎屑 0.15、DETRITUS_REGEN 0.006、开局生产者 260 / 异养 55、地上先放 30 具尸体、异养 maxEnergy ×1.3。实测（seed 5，6000 tick）：三者全程共存，P/C/D 在 220/46/16 到 673/7/30 间振荡，hunts 4532、分解 1328、内共生 2、碎屑 0.02~0.95 大幅波动。**已知问题**：升温到 34°C 会把种群打到个位数（热应激 + 生产者单一气候适应）；物种数 24 上限被打满（谱系churn 太快）；食物网振幅大，尚未做稳定性调优。测试 68 项全绿。

## evo-world 食物网平衡（2026-11-26，承 id:20261126-009）

用户诊断「生产者太弱、消费者太强，生产者一灭绝种群就消失」，据此做了六项平衢：①捕食饱和 SATIATION=0.8（能量过83%容量就不再进食）；②处理时间 HUNT_COOLDOWN=30 tick（杀一次后冷却，防止连锁屠杀）；③异养静息代谢 +0.04/tick；④生产者繁殖阈值 0.64 vs 异养 0.78（生产者是 r 策略方，靠早繁殖回血）；⑤生产者拥挤成本回 0.8×本地密度；⑥分化半径 SPECIATION_RADIUS 由 0.20 降到 0.13（16 个基因下种群间距离实测只有 0.10~0.13，0.2 永远等不到分种）。实测（seed 1234 / seed 3，2400 tick）：种群 650~770 / 280~510，P:C:D 约 550:70:30 与 250:70:18，碎屑 0.1~0.6，封存 corpse 从 4000+ 降到 31 以内，hunts/decompositions 持续发生，三者全程共存。**两个副作用**：①种界是连续的：kind 基因普通突变就能越过 0.5，所以异养会「莫名其妙」变回生产者（这就是之前 P=0 后又能冒出 90 个生产者的原因），若要硬边界得把 kind 改成离散等位基因；②测试节奏：种群涨到 700+ 后全图长跑测试变慢，全套套件从 ~20s 涨到几分钟，得把长跑测试的世界调小。另：本日用富营养化测试改为直接测「无消费者时的再生量」，避免被放牧速率掩盖。
